# Qazi Asmat Kamal | Developer Portfolio

Premium dark portfolio with hover effects and an expandable structure.

## Current JavaScript level
The JavaScript uses only fundamentals already learned:
variables, operators, if/else, switch, loops, arrays, 2-D arrays, functions, parameters and return.

## Profile photo
The uploaded profile photo is included as:
`images/profile.jpg`

It is displayed in the hero section.

## Easy to expand later
- Copy a project card to add another project.
- Copy a skill card to add another skill.
- Copy a service card to add another service.
- Add new JavaScript topics in `script.js`.
- Replace placeholder email/GitHub/LinkedIn links with real details.

\n## Social icons\nWhatsApp, Instagram and Facebook icons have been added with example links.\nReplace the `href` values in `index.html` with your own links/number.\n
