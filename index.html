As-salamu alaykum wa-rahmatullahi wa-barakatuh.

I’m Qazi Asmat Kamal, a beginner web developer and graphic designer building my skills through real projects.

I’ve completed HTML, CSS, JavaScript fundamentals and Bootstrap, and I use them to build responsive, mobile-friendly websites. Alongside web development, I create visual designs in Canva Pro. I’m now learning Git and GitHub to manage code versions and publish my projects.

My design work includes logos, wedding invitations, posters, pamphlets, social media posts, and product and admission ads.

Every project is another step toward becoming a better developer and designer.
